# nanoStudio Overview

**nanoStudio** is the set of real-time production tools that works on top of [nanoStream Cloud](../cloud/cloud_overview). It changes what your viewers see without extra hardware or software on set. The work happens in the cloud pipeline, and the result is delivered with the same **ultra-low latency** as every nanoStream live stream.

nanoStudio uses your existing nanoStream account. You sign in with the same API key or Dashboard login, and your streams, ingest URLs and players stay the same.

:::tip New to nanoStream?
Create a free account in the [nanoStream Cloud Dashboard](https://dashboard.nanostream.cloud/signup), then follow [Getting Started](../cloud/cloud_getting_started) to send your first live stream. Every nanoStudio tool starts from a running stream.
:::

## Chroma Key

Replace a green or blue screen with any background **in the cloud**, live. **One camera feed, multiple outputs**, and you can keep adding outputs as you scale. Each output has its own background, logo overlay, tags and adaptive bitrate (ABR) ladder, so one presenter can appear in several branded studios at the same time.

- Keying runs server-side in the nanoStream pipeline, so viewers need no extra processing
- Browser-based setup and tuning tool with Autotune
- Per-output backgrounds (MP4, PNG, JPG or another live stream) and PNG overlays
- Tune the key, despill, EQ and overlay position in real time while you're live
- Change backgrounds, overlays and tags on a running stream

**Get started:** [Chroma Key: Getting Started](chroma_key_getting_started)

:::info Looking for multi-camera switching or on-demand recording?
These are part of the [nanoStream Real-Time API](../realtime-api/realtime_api_introduction). See [Multi-Camera Switching](../realtime-api/realtime_api_switching) and [On-Demand Recording](../realtime-api/realtime_api_recording).
:::
